# Топ-8 референсов для редизайна Meginn
### Второй репорт: углублённый разбор ключевых проектов из общего ресерча трендов Web3/финтех UI 2026

Это не просто список ссылок, а разбор с проверенными фактами по каждому проекту (цвета, компоненты, механики), которые релевантны Meginn — институциональной платформе управления цифровыми активами, где ключевые задачи UI: доверие, прозрачность операций, мультиподпись/аппрув, ясность данных.

---

## 1. Sui — Site of the Day, Awwwards (июнь 2026)

**Ссылка:** https://www.awwwards.com/sites/sui · сам сайт: https://www.sui.io/

**Что это:** Ребрендинг и новый сайт Layer-1 блокчейн-платформы Sui, сделанный агентствами Holographik и AKKA Studio. Оценка Awwwards — 7.38/10.

**Проверенные факты:**
- Официальная цветовая палитра сайта, зафиксированная Awwwards: **#298DFF** (электрик-синий) + **#000000** (чёрный). Всего 2 цвета — ничего лишнего.
- Отмеченные жюри элементы: анимированный header, градиентные переходы между секциями, интерактивный footer, hover-взаимодействия на странице для разработчиков, кастомные 3D/motion-иллюстрации.

**Почему релевантно Meginn:** прямое подтверждение тезиса «нейтральная база + один уверенный акцент» — именно эта комбинация (чёрный + один синий) в 2026 году считается эталоном для серьёзного Web3-бренда, а не «крипто-неон». Это хороший ориентир именно для маркетингового сайта Meginn — можно взять языком motion/градиентов в hero, но держать строгую двухцветную дисциплину.

## 2. Omega — Crypto Website, Awwwards Honorable Mention

**Ссылка:** https://www.awwwards.com/sites/omega-crypto-website · сайт: https://weareomega.io/

**Что это:** Футуристичный сайт крипто-стритвир-бренда Omega от Redi agency, соединяющий Web3-культуру с визуальным языком мифологии/моды.

**Проверенные факты:**
- Официальная палитра: **#1E1E1E** (почти чёрный графит) + **#D400C6** (насыщенный магента/фуксия) — тот же принцип «тёмная база + один яркий акцент», но с более смелым, не финансовым акцентным цветом.
- Отмеченные элементы: Hero-интро с брендовой анимацией, страница «Philosophy & Brand Vision», магазин мерча, блог.

**Почему релевантно Meginn:** полезен не как прямая стилистика (Omega — retail/lifestyle, не институциональный продукт), а как пример того, как далеко можно зайти с акцентным цветом на маркетинговом сайте, оставаясь в рамках «чёрный/графит + 1 акцент». Для Meginn акцент стоит взять более сдержанный (синий/индиго), но композиционные и motion-паттерны страницы применимы.

## 3. Zerion Wallet — кейс-стади редизайна (Sergey Chudarin, Senior Product Designer)

**Ссылка:** https://chudarin.com/cases/zerion.html

**Что это:** Подробный кейс-стади того, как Zerion (мультичейн Web3-кошелёк/DeFi-платформа) превратился из портфолио-трекера в полноценный кошелёк с подписанием транзакций — за 4.5 года работы одного дизайнера.

**Проверенные факты и метрики:**
- Рост до **400 000+ MAU / 150 000+ DAU**, свыше **$100 000 000** объёма транзакций, 5 млн+ транзакций в месяц.
- Ключевые UX-механики, внедрённые именно для доверия и безопасности: **Transaction Simulation** (симуляция результата транзакции до подписания) и **Phishing Defense**.
- Единая **cross-platform Design System** для iOS, Android, Web и Browser Extension.
- Редизайн навигации («Navigation 3.0») и постоянные UI-аудиты как часть процесса.

**Почему релевантно Meginn:** это, вероятно, самый близкий по духу референс из всех — не по визуалу, а по продуктовой механике. Симуляция транзакции до подтверждения и явная защита от фишинга — паттерны, которые для custody-платформы уровня Meginn являются не украшением, а основой доверия институционального клиента. Кейс также показывает ценность единой дизайн-системы на всех платформах — актуально, если у Meginn кроме веб-аппа есть/будет мобильная версия.

## 4. Fireblocks — живой продукт, прямой конкурентный бенчмарк

**Ссылка:** https://www.fireblocks.com

**Что это:** Институциональная инфраструктура для цифровых активов и стейблкоинов — прямой конкурент Meginn по категории. Клиенты, указанные на сайте: ABN AMRO, BNY, Revolut, Visa, Checkout.com, eToro, Western Union.

**Проверенные факты:**
- Фирменный цвет из мета-тегов сайта — **#212647**, глубокий тёмно-синий/индиго (не чёрный) — вариант «холодной» институциональной базы вместо чисто чёрной.
- Структура сайта построена вокруг явного разделения по продуктам (Wallets, Payments, Security & Governance, Tokenization) и по индустриям клиента (банки, трейдинг, платежи, Web3) — то есть навигация «от задачи клиента», а не «от технологии».
- На главной — блок логотипов enterprise-клиентов сразу под hero (trust-сигнал в первом экране), и кейсы клиентов с конкретными цифрами (например, «Bridge сократил время расчётов с 12+ часов до 90 минут»).

**Почему релевантно Meginn:** это не «тренд-галерея», а прямой ориентир по категории. Показывает эталонный институциональный паттерн: trust-сигналы (логотипы банков/бирж) сразу в первом экране, конкретные метрики результата в кейсах, навигация по индустриям клиента. Стоит открыть сайт напрямую и посмотреть разделы Security/Governance и Tokenization — именно там обычно находится специфика UI для комплаенс-контуров.

## 5. PROPTH — Fintech Dashboard UI Kit (UI8, Figma)

**Ссылка:** https://ui8.net/ito-digital-agency/products/propth---fintech-dashboard-ui-kit

**Что это:** Premium Figma UI-кит дашбордов для финтех-продуктов от студии ITO Digital Agency.

**Что предлагает:** готовый набор компонентов дашборда (графики, таблицы транзакций, карточки метрик, формы) в актуальной фин-тек стилистике — полезен не для копирования дизайна один-в-один, а как быстрая референсная библиотека паттернов компоновки данных (как верстают таблицу транзакций, как показывают тренд на карточке метрики, как строят навигацию дашборда).

**Почему релевантно Meginn:** практическая польза — экономит время на этапе черновой структуры дашборда Meginn (портфель, история операций, аналитика). Смотреть как референс компоновки, не как финальную стилистику — переносить нужно только паттерны, а цвет/скругления/шрифт задавать по собственной системе Meginn.

## Итог: что взять в работу в первую очередь

Для Meginn из этой восьмёрки два референса дают наибольшую практическую пользу:

1. **Fireblocks** — как эталон институциональной архитектуры сайта и trust-сигналов (открыть напрямую, не через галерею).
2. **Zerion (кейс Chudarin)** — как эталон продуктовых механик доверия внутри самого приложения (симуляция транзакции, антифишинг, единая дизайн-система).

Остальные — источник конкретных визуальных и композиционных паттернов (цвет, bento-раскладка, bridge/transfer-состояния).
