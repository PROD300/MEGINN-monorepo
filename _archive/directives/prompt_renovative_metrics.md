# TASK: Обновление системы метрик OBSIDIAN до уровня Tier-1 (Institutional Grade)

## Контекст

В текущей версии проектной документации OBSIDIAN используется система метрик уровня раннего продукта (стартап / прототип), которая не соответствует требованиям институциональных клиентов (фонды, банки, кастодианы, RWA-платформы).

Необходимо полностью пересобрать систему метрик в соответствии с Tier-1 стандартом:

* фокус на управлении капиталом
* контроле операций
* проверяемости (auditability)
* безопасности
* институциональной пригодности

  * brief.md

### 3. Каскадное обновление всей документации

Обязательно синхронизируй изменения во всех зависимых документах:

### 4. Связывание метрик с функциями (обязательно)

Добавь явные зависимости:

* AUM → onboarding, custody, vaults
* Volume → execution, UX, latency
* Approval Coverage → multi-level approval system
* Policy Coverage → policy engine
* Audit Trail → logging system
* Security Incidents → infra + access control

Если метрика не поддержана функциями → это ошибка архитектуры.
