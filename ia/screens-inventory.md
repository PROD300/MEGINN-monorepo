# Инвентаризация экранов — OBSIDIAN v1.0 MVP

## Экраны из PRD

| Имя (латиница) | Что происходит |
|---|---|
| `Portfolio` | Главный экран авторизованного пользователя: текущие активы, аллокация, суммарный AUM по сетям (ETH, Arbitrum) |
| `RebalancingRules` | Список всех активных правил ребалансировки с их статусом (активно / пауза / ошибка) |
| `RuleCreate` | Создание нового правила: выбор порога (threshold), целевого аллокации, сети, условий срабатывания |
| `RuleDetail` | Просмотр и редактирование существующего правила; история его срабатываний |
| `CrossChainBridge` | Статус и история кросс-чейн переводов (F20): активные бриджи, провайдер (Li.Fi/Socket/Across), время и комиссия |
| `EmergencyStop` | Одно нажатие — полная остановка всех автоматических процессов; статус "всё остановлено" |
| `LiabilityDashboard` | Дашборд ответственности: кто отвечает за что, статус правовых соглашений, индикаторы риска |
| `LegalTerms` | Текст юридических условий, подписание соглашения об ответственности кастодиана |
| `AuditLog` | Хронологическая история всех автоматических действий и транзакций с фильтрацией |
| `AuditLogDetail` | Детали конкретного события: хеш транзакции, правило-триггер, входные / выходные параметры |
| `SmartAccountSetup` | Настройка Smart Account: назначение ролей, разрешений, подключение кошельков |

## Служебные экраны (в PRD нет, но без них продукт не соберётся)

| Имя (латиница) | Что происходит |
|---|---|
| `Login` | Авторизация: wallet connect или email + password; выбор типа аккаунта |
| `Onboarding` | Первоначальная настройка Smart Account сразу после регистрации; шаги: сеть → роли → первое правило |
| `Settings` | Настройки аккаунта: профиль, подключённые кошельки, уведомления |
| `Notifications` | Центр уведомлений об автоматических действиях (post-factum, как требует US01 AC3) |
| `NetworkError` | Экран ошибки при недоступности сети / RPC; инструкция что делать |
| `TransactionError` | Ошибка конкретной транзакции (slippage guard сработал, недостаток газа) |
| `EmptyRules` | Состояние "правил ещё нет" с CTA на создание первого правила |
| `EmptyAudit` | Состояние "транзакций ещё нет" на экране AuditLog |
| `NotFound` | 404 — страница не найдена |
