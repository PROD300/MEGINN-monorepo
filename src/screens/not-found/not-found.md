# Screen: Not Found (404)

**Роут:** `/not-found`
**Файл:** `src/screens/not-found/NotFound.tsx`
**Figma:** node 249:2 — Screen/NotFound

## Компоненты из базы

| Компонент | Откуда | Использование |
|-----------|--------|----------------|
| `AppTopBar` | base | Верхняя панель — присутствует в макете (служебный экран всё же рендерится внутри авторизованного шелла, по скриншоту видно AppTopBar + AppSidebar) |
| `AppSidebar` | base | Боковое меню без `active` — в макете подсвечен Portfolio, но это технический дефолт компонента в Figma, не семантика страницы 404, поэтому активный пункт не проставлен |
| `Button` | base | "Back to Portfolio" / "Go to Dashboard" (primary, sm, растянуты на 50% через flex) |

## Локальные части (доменные, inline в файле экрана)

| Блок | Описание |
|------|----------|
| `NotFoundCard` | Центрированная карточка: "404" + divider + "Page not found" + описание + CTA-кнопки + ссылка поддержки. Простая композиция на токенах, не требует выноса в базу (одноразовый паттерн страницы ошибки). |

## Статика (контент из макета)

- "404", "Page not found"
- "The page you're looking for doesn't exist or may have been moved. Check the URL and try again."
- Кнопки: "Back to Portfolio", "Go to Dashboard"
- "Need help? Contact support →"

## Расхождения с макетом

- Активный пункт сайдбара не проставлен (в макете Figma по умолчанию подсвечен Portfolio — посчитано артефактом дефолтного стейта компонента, не значимым для статичной 404-страницы).

## Подтверждение

Логика, обработчики, состояние и слой данных не добавлены — экран полностью статичный. Ссылка поддержки и кнопки рендерятся, но никуда не ведут (href="#", без onClick).
