## TL;DR для агента

Проект сейчас на **Inter** — это главная слабость типографики. Рекомендация по итогам исследования 30 Web3/финтех-проектов: перевести на **Geist + Geist Mono** и добавить отсутствующий числовой TextStyle с табличными цифрами.

**Это ребрендинг-изменение.** По `ds/CONTRACT.md` («Что запрещено») перезапись Variables без явной команды ребрендинга запрещена. Daria исследование заказала и рекомендацию получила, но **явного «делай» на момент хэндовера не давала** — перед правкой токенов подтверди у неё решение по шрифту.

## Обоснование (коротко)

Из 30 разобранных проектов:

- Крупные крипто-бренды заказывают кастомные шрифты: Coinbase Sans (+Mono), Base Sans (+Mono), Aptos Season, Polkadot Unbounded.
- Средний сегмент лицензирует премиальные гротески: Söhne (Stripe, Mercury), Aeonik (Revolut), ABC Diatype, Suisse Int'l.
- Inter у брендов с кастомом встречается в основном **как фолбэк** (официальный фолбэк-стек Base: Inter Tight → Inter → Roboto Mono), а как основной шрифт остаётся у тех, кто не дошёл до брендинга. Отраслевые обзоры 2026 прямо называют Inter/Helvetica в финтехе сигналом отсутствия инвестиции в бренд.
- **Универсальный паттерн: пара sans + mono из одной системы.** Coinbase Sans/Mono, Base Sans/Mono, Söhne/Söhne Mono, Geist/Geist Mono, Diatype/Diatype Mono. Моно нужен для сумм, адресов кошельков, хешей транзакций, таймстемпов. Coinbase документирует, что их типографика вдохновлена моноширинными шрифтами исторических финансовых документов.
- **Табличные цифры обязательны.** Base отдельно документирует выравнивание табличных цифр в колонках данных.

Почему Geist для Obsidian: нативная пара sans+mono (закрывает главный пробел), инженерный характер совпадает с текущими токенами (Ice Blue `#0EA5E9`, холодные серые, острый радиус 4px), заметно отличается от Inter без потери читаемости, бесплатный и опенсорсный — пригоден для портфолио и публичного репозитория.

Платный апгрейд, если появится бюджет: **ABC Diatype + Diatype Mono** (Dinamo) или **Söhne + Söhne Mono** (Klim).
Избегать: Montserrat/Poppins/Work Sans (шаблонность), декоративные «футуристичные» крипто-шрифты (противоречат институциональному позиционированию).

## Правило применения шрифтов (главное — читать перед правками)

### Роли в паре

| Шрифт | Роль | Где применяется |
|-------|------|-----------------|
| **Geist** (Sans) | **Основной.** ~90% всего текста в продукте | Навигация, заголовки всех уровней, body-текст, лейблы, кнопки, поля форм, подписи, пустые состояния, тексты ошибок |
| **Geist Mono** | **Служебный / числовой.** Строго функциональная роль | Только данные: суммы, балансы, P&L, проценты, тикеры, адреса кошельков, хеши транзакций, таймстемпы, gas, ID правил, номера блоков |
| **Geist Pixel** | **Не использовать в продукте** | Максимум — акцент на маркетинговом лендинге, только по отдельному согласованию с Daria |

### Ключевое уточнение: Mono — не «акцентный» шрифт

Geist Mono **не является акцентным** в декоративном смысле. Его нельзя брать «для характера» на заголовки, hero-текст, кнопки, названия разделов или чтобы «оживить» вёрстку. Единственное основание применить Mono — **это число или технический идентификатор, который пользователь сканирует, сравнивает или выравнивает по колонке.**

Правило одной фразой: **Mono — там, где данные, Sans — везде остальное.**

### Проверочный вопрос перед применением Mono

Если ответ «нет» хотя бы на один — ставится Geist Sans:

1. Это число, адрес, хеш, тикер или технический ID?
2. Пользователю важно сравнить его с другим таким же значением (в колонке, в строке, между карточками)?
3. Значение может обновляться в реальном времени?

**Примеры разграничения:**

| Элемент | Шрифт | Почему |
|---------|-------|--------|
| `$1,284,300.50` в StatCard | Mono | число, обновляется, сравнивается |
| Заголовок «Total Portfolio Value» над ним | Sans | это лейбл, а не данные |
| `0x7a3f...c19b` | Mono | адрес кошелька |
| «Rebalancing Rules» в сайдбаре | Sans | навигация |
| `+2.4%` в строке актива | Mono | число в колонке |
| «Rule executed successfully» в Toast | Sans | обычный текст |
| `2026-08-09 14:32:07` в AuditLog | Mono | таймстемп, выравнивается по колонке |
| Кнопка «Confirm Transaction» | Sans | интерактивный элемент |
| `12 gwei` в поле gas | Mono | техническое значение |

### Почему это важно именно для Obsidian

Без табличных цифр и без разделения ролей цифры в дашборде «дрожат» при обновлении значений и не выравниваются в колонках таблиц — это первое, что бросается в глаза в custody-продукте и ровно та причина, по которой шрифт вообще меняется. Обратная ошибка (Mono везде подряд) превращает институциональный интерфейс в «терминал ради терминала» — тоже неприемлемо.

## Текущее состояние в коде (проверено)

`app/src/tokens/primitives.css`:
```css
--font-sans: 'Inter', system-ui, sans-serif;
--font-mono: ui-monospace, 'SFMono-Regular', 'Roboto Mono', Consolas, monospace;
```
→ Моно-токен объявлен, но указывает на системные шрифты. Фирменного «числового» голоса у продукта нет.

`app/src/tokens/typography.css`:
- Строка 5: `@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap');`
- 10 классов TextStyles: `.ds-heading-4xl/3xl/2xl/xl/lg`, `.ds-body-base/sm/sm-medium/xs`, `.ds-label-xs`.
- **Ни один из 10 стилей не отвечает за числовые данные.** Это пробел ДС, а не только вопрос выбора шрифта.

## План внедрения

1. **Подтвердить решение у Daria** (ребрендинг-шаг, см. выше).

2. `app/src/tokens/primitives.css` — заменить значения:
```css
--font-sans: 'Geist', system-ui, sans-serif;
--font-mono: 'Geist Mono', ui-monospace, monospace;
```

3. `app/src/tokens/typography.css` — убрать `@import` Inter. Способ подключения Geist — см. раздел «Подключение Geist: важные ограничения» ниже. **Не подключать через Google Fonts CDN** — там урезанная версия без `font-feature-settings`, а именно через них включаются табличные цифры.

4. Добавить недостающий числовой стиль (новый TextStyle `DS/Numeric`):
```css
.ds-numeric {
  font-family: var(--font-mono);
  font-variant-numeric: tabular-nums;
  letter-spacing: 0;
}
```

5. Применить `.ds-numeric` там, где живут данные:
   - Компоненты: `StatCard`, `Table`, `ActivityRow`, `LiabilityCard`
   - Экраны: `Portfolio`, `AuditLog`, `LiabilityDashboard`, `CrossChainBridge`
   - Данные: суммы, балансы, P&L, тикеры, адреса кошельков, хеши транзакций, таймстемпы, ID правил, gas

6. **Зафиксировать по процессу ДС** (`ds/CONTRACT.md` → «Что делать, если нужного нет»):
   - записать новый TextStyle в `ds/foundation.md`;
   - синхронизировать Variables и TextStyles в Figma (страница Foundation `18:2` → фрейм «Foundation-Tokens» `35:2`), иначе код и дизайн разъедутся. Figma-файл: https://www.figma.com/design/PcpLlKJqePv7h5acIUEgfd/Obsidian-MCP

7. **Проверить визуально**: `npm run storybook` в `app/` — прогнать `Foundation.stories.tsx` и компоненты с данными; убедиться, что цифры не «дрожат» при обновлении значений и метрики выравниваются в колонках таблиц.

8. Консистентность соседей (стоячее правило проекта из `CLAUDE.md`): после правки одного компонента сверить все однотипные — типографика должна поменяться везде, а не только в починенном.

## Подключение Geist: важные ограничения

Проверено на официальной странице шрифта https://vercel.com/font (2026-08-09).

### Где смотреть и брать

| Ресурс | Ссылка |
|--------|--------|
| Официальная страница + интерактивный playground | https://vercel.com/font |
| Geist Sans на Google Fonts | https://fonts.google.com/specimen/Geist |
| Geist Mono на Google Fonts | https://fonts.google.com/specimen/Geist+Mono |
| Скачать файлы (otf / woff2 / variable) | https://github.com/vercel/geist-font/releases/latest |

### Лицензия

**OFL** (SIL Open Font License) — https://github.com/vercel/geist-font/blob/main/LICENSE.txt
Свободно используется в коммерческих проектах, портфолио и публичных репозиториях. Ограничений для Obsidian нет.

### Критично: Google Fonts даёт урезанную версию

Официальная таблица сравнения способов установки:

| Возможность | NPM | Google Fonts | .zip |
|-------------|-----|--------------|------|
| `font-feature-settings` | да | **нет** | да |
| Полный набор глифов | полный | **частичный** | полный |
| Автообновление | через npm | через Google | вручную |

**Для Obsidian это блокирующее ограничение.** Табличные цифры (`tabular-nums`) включаются именно через feature settings — а без них цифры в дашборде будут «дрожать» при обновлении значений и не выровняются в колонках таблиц. Это ровно та причина, по которой шрифт вообще меняется.

**Вывод для агента:**
- Продакшен — ставить через npm: `npm i geist` (проект уже на npm, `app/package.json` есть), либо положить файлы из .zip локально в `app/src/assets/fonts` и подключить через `@font-face`.
- Google Fonts CDN — **только** для быстрого прототипа/чернового просмотра, в финальную сборку не тащить.
- Проект на Vite + React (не Next.js), поэтому готовые импорты вида `geist/font/sans` из документации Vercel напрямую не подойдут — они рассчитаны на `next/font`. Нужно подключать сами файлы шрифта из пакета через `@font-face` в CSS-токенах.

### Почему эта пара действительно метрически согласована

Geist изначально разрабатывался **как моноширинный** — Vercel сначала сделали Mono для кодовых сред, и уже потом вырастили из него Sans и Pixel. То есть sans и mono идут из одного скелета, а не подгонялись друг под друга задним числом. Для интерфейса, где моно-цифры стоят вплотную к обычному UI-тексту (карточки метрик, строки таблиц, ActivityRow), это даёт ровную оптическую линию — редкое качество для бесплатной пары.

### Geist Pixel — не использовать в продукте

В семействе есть третий вариант, **Geist Pixel** (пиксельный, вариативная ось `ELSH` с пятью формами: square / circle / grid / triangle / line). Для институционального custody-продукта он не подходит — противоречит позиционированию. Допустим максимум как акцентный элемент на маркетинговом лендинге, и то по отдельному согласованию с Daria.
